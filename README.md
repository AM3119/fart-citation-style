# FART — Fancy Academic Reference Thingy

A multidisciplinary author–date citation style and companion tooling project.

## Current status

**Redesign draft 0.6.** The style has been revised around the new FART editorial rules: lowercase titles, bold declaration-style prefixes, `and also` between multiple citations, full names for the first three bibliography authors, `AC` year markers, and labeled DOI/PubMed identifiers. These changes are not yet revalidated or fully tested across Zotero item types.

## Try it in Zotero

This is an experimental redesign. Revalidate and test it with representative Zotero records before using it in a live manuscript. Installation instructions:

1. Download [fart.csl](fart.csl).
2. In Zotero, open **Settings/Preferences → Cite → Styles**.
3. Drag the downloaded `.csl` file into the Styles list (or use the add-style control).
4. Select **FART — Fancy Academic Reference Thingy** in your word processor's citation style selector.
